# Music Player (PWA)

Reproductor de música simple. Lee canciones desde el propio teléfono (las elegís con el botón "+"), tiene aleatorio, repetir, barra de progreso, y se puede "instalar" como app desde el navegador.

## Cómo publicarla (igual que las otras apps)

1. Creá un repositorio nuevo en GitHub (botón verde "New").
2. Subí todos los archivos de esta carpeta a ese repositorio (podés arrastrarlos desde la web de GitHub con "Add file > Upload files", o por terminal con git).
3. Andá a **Settings > Pages** del repositorio.
4. En "Branch" elegí `main` y la carpeta `/root`, guardá.
5. Esperá 1-2 minutos y GitHub te va a dar un link tipo `https://tu-usuario.github.io/tu-repo/`.
6. Abrí ese link desde el celular. Para "instalarla" como app: en Chrome tocá el menú (⋮) y "Agregar a pantalla de inicio".

## Cómo se usa

- Tocá el botón "+" y elegí las canciones de tu teléfono (podés seleccionar varias a la vez).
- Se arma la lista abajo; tocá cualquier canción para reproducirla.
- Los controles de aleatorio y repetir están arriba de la barra de progreso.
- Si bloqueás la pantalla, la música sigue sonando y aparecen los controles en la pantalla de bloqueo.
